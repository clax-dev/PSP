3 · CALLABLE + FUTURE · C02 parte 2 · WriteCSV

El ticket del pedido

Pido, me dan un ticket, sigo a lo mío… y con el ticket recojo el resultado cuando lo necesito.

El tipo viaja de punta a punta 
Callable<Path>  → call() da Path
submit()       → Future<Path>
future.get()   → Path
Los errores también viajan en el ticket
Si call() falla, no lo ves… hasta el get(), que lanza ExecutionException. La causa real: e.getCause() / «Caused by:». (te pasó con LocalDate)
⑤ Al final, shutdown()
Recogidos todos los tickets, cierras la cafetería.

Run ↔ Callable: start() llama a run(); submit() hace que el pool llame a call().

3 · CALLABLE + FUTURE · EL ERROR TÍPICO

Primero repartir todo, después recoger todo

5 tareas, pool de 3 hilos. Cada tarea tarda lo mismo (1 bloque).

// ❌ MAL
for (int i = 1; i <= 5; i++) {
    Future<Path> f = pool.submit(new WriteCSV(i));
    f.get();               // espera aquí → serializa
}
// ✅ BIEN
for (int i = 1; i <= 5; i++)                // BUCLE 1: repartir
    futures.add(pool.submit(new WriteCSV(i)));
for (Future<Path> future : futures) {      // BUCLE 2: recoger
    Path ruta = future.get();
    mostrarInfo(ruta);
}
pool.shutdown();
En la llamada se pasa la variable: mostrarRutas(futures) ✅ — nunca el tipo: mostrarRutas(Path) ❌
